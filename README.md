# Web Technologies Quiz (CSC336 – Assignment 2)

Responsive, interactive quiz built with HTML, CSS, JavaScript and Bootstrap 5.

**Features**
- 5 randomized questions per run (12-question bank, options shuffled too)
- Multi-colored segmented progress bar
- 15-second countdown per question (auto-reveals answer on timeout)
- Correct answer turns green, wrong choice turns red
- Dark / light mode toggle (remembers choice)
- Download results as PDF (jsPDF + AutoTable)
- Fully responsive (mobile → desktop)

**Run:** open `index.html` in a browser (internet needed for the CDN libraries).
